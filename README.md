# Helixa Agent Skills

Agent skills for the [Helixa](https://helixa.xyz) identity and credibility protocol, built for the [skills.sh](https://agentskills.io) ecosystem.

## Install

```bash
npx skills add helixa
```

## What's Included

The `helixa` skill teaches AI agents to:

- 🔍 **Check credibility** — Query cred scores (0-100) with tier breakdowns
- 🪪 **Look up identity** — Find agents by address or name
- 🔎 **Search agents** — Browse the registry with filters
- ⛏️ **Mint identity** — Register on-chain via V2 contract on Base
- 📊 **Report outcomes** — Submit session results for cred tracking
- 🔒 **Manage souls** — Check lock status and version history
